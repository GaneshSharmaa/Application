## 🧠 About
Mitra is your intelligent assistant built using Flutter and AI frameworks. It can engage in natural conversation, understand voice commands, and handle tasks like reminders, small talk, and more.

---

## ✨ Features
- Voice and text input support  
- Conversational flow control with state management  
- Responsive and intuitive UI  
- Easily extendable with plugin modules (e.g., weather, reminders)  
- Modular architecture for scalability

## 🧩 Installation

### Prerequisites:
- [Flutter SDK](https://flutter.dev/docs/get-started/install) (v3.0+)
- Android Studio or Visual Studio Code
- Git installed

### Steps:

```bash
# 1. Clone the repository
git clone https://github.com/MITRA0616/Application.git
cd Application

# 2. Get project dependencies
flutter pub get

# 3. Run on device/emulator
flutter run
```

---

## 🎯 Usage
- Start the app on a connected device or emulator  
- Use text or voice to interact with Mitra  
- Customize the chatbot behavior in `lib/` directory
